## Independent creator continuity

VIDMAGE is intended to serve a creator who may also have a private planning/workflow home. Do **not** mirror private PaulaOS/King's Cup files, ideas, finances, works-in-progress or private repo code into this public repository. Offer a later opt-in handoff that carries only a selected project reference and permitted content.

## Reuse rule

Publicly readable does not necessarily mean legally reusable source. Inspect license, media grants and third-party notices before source copy or vendoring. Prefer isolated adapters that call existing local binaries on clearly defined inputs, and confirm the donor contract with tests.
