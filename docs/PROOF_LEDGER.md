## Truth gates for VIDMAGE

Before describing any capability as **VIDMAGE READY**, require:
1. Donor exact SHA, license/usage rights, runtime dependencies and test evidence.
2. Versioned VIDMAGE adapter with synthetic fixture tests and explicit failure states.
3. Output files inspected (ffprobe video/audio/duration, SHA, receipt).
4. First-user performance with human selection, edit/rerender, project reopen, and no unintended media upload or paid spend.

Landed/unmerged, passing/failing and publicly deployed/not deployed are **independent axes**. Report them separately.
