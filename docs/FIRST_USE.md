# First use: make a complete video

**User story:** An independent creator wants to make a short video without learning developer tools.

1. Open **New Video**. Choose **Song**, **Story**, **Explain**, or **Promote**. Disable options not yet supported by actual code.
2. Bring authorized local media: photos, short clips, optional song/voice. Intake keeps originals intact, shows what is local, and asks before any provider upload.
3. Choose a rough direction. Get an *entire* viewable first cut from local deterministic rendering whenever compatible inputs exist.
4. Watch the actual MP4. Select one weak section. Choose a replacement from proposals, or edit placement, trim or timing.
5. Make a revised cut without losing the previous one. Changes to a preview never silently rewrite prior evidence.
6. Export locally and inspect the selected final version. Public posting and commercial delivery are separate, intentional decisions.

## Pass/fail conditions

- PASS: one actual playable MP4, second materially different MP4, source manifests, output hashes, project reopened from disk, audio and duration inspected using ffprobe.
- PASS: public repository contains only synthetic fixtures; consent checked before third-party media transfers.
- PASS: default local path does not consume paid credits.
- FAIL: only a mock screen, timeline plan without render, fake success status, preview falsely described as a final file, or an accepted edit that cannot survive restart.

## High-leverage later modes

Children's picture-book videos; narration with captions; two-character paper theater; music videos; educational or business explainers; reels/shorts; reusable visual series. These are goals until separately proven.
